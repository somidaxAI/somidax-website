# Somidax Website

Official website for [Somidax](https://somidax.net) — AI-native e-commerce network.

Built with React 19, Vite 8, TypeScript, and Tailwind CSS v4.

## Development

```bash
npm install
npm run dev
```

## Deploy

Pushes to `main` automatically deploy to GitHub Pages via the Actions workflow.
